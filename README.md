# Simple Zombie Shooter

Top-down браузерный зомби-шутер: волны зомби, три вида оружия, три арены.
Phaser 3 + Vite, чистый JavaScript (без фреймворков и сборочных обёрток).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # локальный просмотр прод-сборки
```

### Отладка

- `http://localhost:5173/?debug=1` — визуализация физ. тел Arcade.
- `window.__game` (только в dev-сборке) — доступ к инстансу Phaser Game
  из консоли/автотестов: `__game.scene.getScene('Game')`, `('UI')`, `('Menu')`.
- Папка `debug/` — puppeteer-скрипты-регресс (`node .\debug\debug_<сцена>.mjs`,
  требуется запущенный dev-сервер). Критерий здоровья: `ИТОГ pageerror: 0`.

## Карта модулей

```
src/
  main.js                 — конфиг Phaser (960×640, FIT), ?debug-флаг,
                            window.__game только в DEV
  scenes/
    BootScene.js          — загрузка ассетов + процедурные текстуры
    MenuScene.js          — меню, рекорд, управление
    GameScene.js          — «сборка + коллайдеры + игровые события»;
                            тонкие делегаты сохраняют старое API сцены
                            (scene.clampBulletRange(...) и т.п.)
    UIScene.js            — HUD с dirty-check'ами (интстанс переживает
                            рестарт — кэши сбрасываются в create())
  entities/
    Player.js             — движение WASD, прицел, стрельба, аптечка heal()
    Zombie.js             — погоня, атака, knockback с экспон. затуханием
    Bullet.js             — пуля из пула (несёт damage + knockback)
  physics/
    depenetration.js      — выталкивание тел из препятствий, разводка
                            динамических пар (контракт: сцена отдаёт
                            player / zombies / obstacleCache)
    raycast.js            — обрезка дальности пуль: slab-проход по тайлам
                            + «луч↔круг» для стволов
  systems/
    WaveManager.js        — паузы между волнами, перемешанная очередь
                            спавна, выбор точек спавна
    PickupManager.js      — пикапы: аптечки/ящики боезапаса падают
                            из зомби (шанс), лежат lifetime, подбор
                            по расстоянию
  world/
    LevelBuilder.js       — пол, ящики/стены, деревья (круглый ствол)
                            и кусты, плоский obstacleCache
  data/
    depth.js              — единая карта слоёв отрисовки DEPTH
    levels.js             — геометрия арен в тайлах + ширина/высота
    waves.js              — раскладки волн
    pickups.js            — конфиг пикапов (heal/amounts/шанс/жизнь)
    weapons.js            — урон/темп/разброс/knockback по оружию
    zombies.js            — типы зомби (hp, скорость, mass)
    highscore.js          — рекорд в localStorage
  audio/
    sfx.js                — процедурные SFX на WebAudio (ноль аудио-файлов):
                            осциллятор/шум + огибающая; контекст
                            разблокируется первым жестом, mute — клавиша M
```

## Осевые правила кода

- **Слоты глубин** — только из `data/depth.js` (сцены не пишут
  магические `.setDepth(100)`).
- **Зомби**: hp 60/40/180, масса отброса `mass` — «чем больше, тем тяжелее»
  (walker 1.0 · runner 0.7 · brute 2.75), импульс = `knockback / mass`.
- **Пули** не имеют физического коллайдера с препятствиями — дальность
  отсекается лучом так, чтобы визуальная грань тайла была точной.
- **Жизненный цикл**: обновления растительности/волн живут только при
  `gameState === 'playing'`; на завершении (`endGame`/`levelCompleted`)
  альфа юнитов восстанавливается принудительно.
- **Звук**: эффекты синтезируются кодом (`audio/sfx.js`), без ассетов.
  Один звук на спусковой крючок (веер дробовика не наслаивается),
  пер-эффектный троттлинг, M — mute (master gain 0, индикатор в HUD,
  есть в меню).
  Мастер-шина уходит в `createDynamicsCompressor()` — эффекты разного
  имени не троттлятся между собой, компрессор гасит клиппинг при толпе.
  Нюанс: первое нажатие M только разблокирует AudioContext, глушение
  — со второго. Неизвестное имя эффекта в DEV даёт `console.warn`.
- **Пикапы**: подбор — проверка расстояния в `updatePickups`, не
  Arcade-overlap (у пикапов нет тел, O(kits)/кадр дешевле и надёжнее).
  Бесполезный пикап не расходуется: аптечка при полном HP, ящик
  когда всё оружие под шапками — лежит до конца lifetime.
  `scene.pickups` пересоздаётся в `initPickups` (`= []`, не `??=`):
  рестарт сцены не должен накапливать мёртвые записи.
  Шансы дропа зависимые: ящик бросается только если не выпал медкит,
  эффективный шанс =(1−0.12)×0.10≈0.088 — см. `data/pickups.js`.
- **Боезапас из ящиков**: пополнение склэмпится шапкой —
  2× начального боезапаса оружия (`WEAPONS[id].ammo * 2`),
  базовые конфиги оружия не мутируются.

## Контент: уровни и волны

Конфиги уровней (`levels.js`) и волн (`waves.js`) параллельные массивы —
**при добавлении уровня добавляйте его раскладку волн** (индексы связаны).
Рассинхрон ловится guard'ом в GameScene.create() с console.error.

Содержимое: 4 уровня — «Начальный лагерь», «Двор склада», «Цитадель»,
«Последняя застава» (финал: форт с двумя воротами, 4 волны,
состав до `{walker 16, runner 12, brute 4}`).

## Управление

- `WASD` — движение, мышь — прицел, `ЛКМ` (удерживать) — стрельба,
  `1/2/3` — пистолет (∞) / дробовик / автомат, `R` — рестарт после смерти,
  `M` — звук вкл/выкл.
